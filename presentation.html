INTRODUCTION
•
Urbanization & Microclimate Shifts: Localized meteorological variations significantly impact human health, agricultural yields, industrial workspaces, and smart city infrastructure.
•
Limitations of Conventional Stations: Traditional weather monitoring setups are bulky, expensive, lack cloud accessibility, and provide low temporal resolution with noticeable reporting lag.
•
The Role of IoT & Embedded Systems: Internet of Things (IoT) enables distributed, low-power, and compact sensing nodes that capture environmental parameters autonomously in real time.
•
Core Implementation Technology: Utilizing the dual-core ESP32 microcontroller with integrated 2.4 GHz Wi-Fi to acquire high-precision temperature and humidity readings from a DHT22 sensor.
•
Edge & Cloud Synergy: Sensor telemetry is simultaneously rendered locally on an I2C SSD1306 OLED display for immediate observation and pushed to ThingSpeak IoT Cloud for remote web analytics.

OBJECTIVES
✔
Autonomous Embedded Station: To design and fabricate an autonomous, low-power IoT Weather Monitoring Station using the ESP32 microcontroller.
✔
High-Precision Atmospheric Sensing: To interface a calibrated DHT22 (AM2302) sensor to measure temperature (±0.5°C) and relative humidity (±2%).
✔
Local Visual Feedback: To establish high-speed I2C communication with an SSD1306 0.96" OLED display for real-time edge telemetry readout.
✔
Comfort Index Computation: To calculate Heat Index (Steadman formula) and Dew Point (Magnus formula) directly on-device.
✔
Cloud Telemetry Pipeline: To push sensor telemetry every 20 seconds to MathWorks ThingSpeak IoT Cloud via RESTful HTTP API.
✔
Serverless Global Dashboard: To build and host a responsive web application on Vercel featuring 24-hour dynamic HTML5 canvas trend graphs.

DESCRIPTION: HARDWARE ARCHITECTURE
Component Technical Specification Pin Interface Role in System
ESP32 Dev Board Xtensa Dual-Core 32-bit, 240MHz, 2.4GHz 802.11 b/g/n Wi-Fi Micro-USB / 3.3V Master controller, data computation & HTTP client
DHT22 (AM2302) -40 to 80°C (±0.5°C), 0 to 100% RH (±2%), 0.5Hz rate GPIO 4 (Digital 1-wire) Precision temperature and relative humidity acquisition
SSD1306 OLED 0.96" Monochrome 128x64 pixels, I2C protocol SDA: GPIO 21, SCL: GPIO 22 Real-time edge telemetry display and connection indicator
Power Source 5V DC via USB / Mobile Hotspot Tethering VIN / 3.3V LDO Supplies regulated power to MCU, sensor, and display
PIN INTERCONNECTION SCHEME
• DHT22: VCC ➜ 3.3V | DATA ➜ GPIO 4 (10kΩ pull-up) | GND ➜ GND
• SSD1306 OLED: VCC ➜ 3.3V | GND ➜ GND | SDA ➜ GPIO 21 | SCL ➜ GPIO 22
• System Flow: DHT22 ➜ ESP32 (Local Math) ➜ OLED Screen + Wi-Fi HTTP POST ➜ ThingSpeak Cloud ➜ Vercel Web Dashboard

DESCRIPTION: SOFTWARE & CLOUD STACK
ESP32 Firmware
• Written in C++ (PlatformIO / Arduino).

• Reads DHT22 sensor via Adafruit Sensor Unified library.

• Calculates Heat Index and Dew Point on-chip.

• Drives OLED via Adafruit_SSD1306.

• Pushes telemetry to ThingSpeak every 20 seconds.
ThingSpeak IoT Cloud
• Channel ID: 3531601 (Public access).

• Field 1: Temperature (°C)
• Field 2: Humidity (%)
• Field 3: Heat Index (°C)
• Field 4: Dew Point (°C)

• Timestamped cloud storage and REST API.
Frontend Dashboard
• Built with Vanilla HTML5, CSS3 & ES6 JS (Zero npm dependencies).

• Live polling every 2s via fetch() API.

• Custom HTML5 Canvas 2D charting of last 48 readings (~24 hours).

• Dynamic Min/Max extremes detection.

• Deployed on Vercel CDN globally.

CONCLUSION & FUTURE SCOPE
CONCLUSION
• Successfully designed and deployed an end-to-end IoT Weather Station combining edge sensing with cloud computing.
• The DHT22 sensor and ESP32 demonstrated stable, accurate telemetry acquisition with local OLED visualization and cloud transmission.
• The serverless web dashboard deployed on Vercel delivers seamless, responsive real-time graphical monitoring accessible globally from any web browser without installation.
FUTURE SCOPE
• Multi-Sensor Expansion: Integration of BMP280/BME280 for barometric pressure, rain gauge, and UV index detection.
• Energy Harvesting: Solar panel and TP4056 Li-ion battery charging circuit with ESP32 deep-sleep modes for off-grid field deployment.
• Automated Alerts: Implementation of Telegram / SMS / Email Webhook triggers for severe weather warnings and heat stress alarms.
• Predictive Analytics: Applying machine learning models on stored ThingSpeak feeds to forecast localized rain and temperature patterns.
