BACKGROUND & PROBLEM STATEMENT

Introduction & Context

03 / 10
📍

The Microclimate Problem

Standard meteorological stations are situated tens of kilometers apart at regional airports, failing to reflect microclimates inside urban canyons, agricultural greenhouses, server rooms, and smart buildings.

⚠️

Limitations of Conventional Stations

Commercial meteorological equipment is bulky, cost-prohibitive ($1,000+), requires manual maintenance, and lacks real-time cloud data pipelines for instant mobile/desktop visualization.

⚡

The IoT Embedded Solution

By leveraging the dual-core ESP32 microcontroller with built-in Wi-Fi and high-precision DHT22 capacitive sensors, we establish an autonomous sensing station operating under $15.

🌐

Edge + Cloud Synergy

Local I2C OLED display guarantees zero-latency visual feedback on-site even when offline, while ThingSpeak and Vercel deliver global, web-accessible telemetry to any connected device.

SYSTEM GOALS

Design & Engineering Objectives

04 / 10
1. Precision Edge Sensing
Interface the DHT22 (AM2302) sensor to acquire real-time atmospheric temperature (±0.5°C) and relative humidity (±2%) with high digital noise immunity.
2. Edge Comfort Math
Compute secondary physiological metrics directly in firmware: Heat Index (Steadman equation) and Dew Point (Magnus equation) for thermal safety assessment.
3. Local OLED Telemetry
Establish 400kHz I2C bus communication with an SSD1306 0.96" OLED screen for instant local readout and Wi-Fi link diagnosis.
4. Cloud Telemetry Ingest
Construct a 4-field RESTful HTTP POST pipeline streaming live telemetry to MathWorks ThingSpeak IoT Cloud every 20 seconds.
5. Zero-Dependency Web UI
Architect a clean vanilla web dashboard (HTML5 / CSS3 / ES6) with custom HTML5 Canvas dual-trace historical trend charts.
6. Serverless Cloud Host
Deploy continuously via Vercel edge infrastructure and open-source all firmware and dashboard assets on GitHub.

HARDWARE IMPLEMENTATION

Hardware Architecture & Interfacing

05 / 10
CONTROLLER
ESP32 DevKit V1
• 32-bit Tensilica Dual-Core @ 240MHz
• 2.4 GHz 802.11 b/g/n Wi-Fi + BLE
• 520 KB SRAM & 4MB Flash
• Low-power standby cycling
SENSOR
DHT22 (AM2302)
• Temp: -40 to 80°C (±0.5°C accuracy)
• Humidity: 0 to 100% RH (±2% accuracy)
• Digital 1-wire communication (GPIO 4)
• Long-term signal stability
DISPLAY
SSD1306 0.96" OLED
• 128x64 Monochrome Pixel Matrix
• I2C Interface: SDA (21), SCL (22)
• High contrast ratio (self-emitting)
• Power consumption ~0.08W

DATA PIPELINE

Software, Cloud & Dashboard Stack

06 / 10
PHASE 1
Sensor Sampling
ESP32 firmware reads the DHT22 pulse train every 2 seconds. Verifies checksum to discard noisy readouts.
PHASE 2
Edge Mathematics
Computes Heat Index and Dew Point on-chip. Renders instantaneous telemetry on SSD1306 OLED via I2C.
PHASE 3
ThingSpeak Cloud
Every 20 seconds, ESP32 transmits a JSON payload to MathWorks ThingSpeak Channel 3531601 across 4 data fields.
PHASE 4
Vercel Web App
Static dashboard pulls latest 48 feeds, recalculates Min/Max extremes, and plots 24-hr canvas graphs.
ThingSpeak Cloud Channel ID: 3531601  |  Field 1: Temperature (°C)  |  Field 2: Humidity (%)  |  Field 3: Heat Index (°C)  |  Field 4: Dew Point (°C)
